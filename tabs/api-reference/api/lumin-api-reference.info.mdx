## Authentication

### API key (`ApiKey`)

Provide your API key in the `Authorization` header, for example `Authorization: API-key`.

|                       |             |
| --------------------- | ----------- |
| Security scheme type  | apiKey      |
| Header parameter name | `X-API-Key` |

### Bearer token (`BearerAuth`)

Provide your token in the `Authorization` header, for example `Authorization: Bearer JWT`.

|                           |        |
| ------------------------- | ------ |
| Security scheme type      | http   |
| HTTP Authorization scheme | bearer |
